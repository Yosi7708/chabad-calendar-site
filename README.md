# אתר לוח חב״ד

אתר סטטי בעברית, מיועד ל-GitHub Pages, עם עמוד מוצר ומדיניות פרטיות.

## לפני פרסום

1. לעבור על המדיניות מול הגרסה שתישלח ל-Google Play וספקי השירות שיופעלו בה.
2. להציג את כתובת התמיכה גם בפרטי יצירת הקשר של דף החנות.
3. להפעיל Pages ממסלול GitHub Actions או מהענף הראשי.
4. להשתמש בכתובת HTTPS של האתר בפרופיל המפתח ובכתובת `privacy.html` בתור מדיניות הפרטיות.

האתר אינו מכיל טופס שאוסף מידע, קובצי מעקב או ספריות ניתוח.
